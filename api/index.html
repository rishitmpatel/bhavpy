    API reference¶

    Daily OHLCV history for NSE stocks and indices, raw and corporate-action adjusted.

    ensure_market(start, end=None) ¶

    Download (once) every NSE equity bhavcopy in the range into the cache.

    raw_history(symbol, start, end, series=None) ¶

    Unadjusted daily rows for a stock across all its historical tickers.

    history(symbol, start=None, end=None, *, adjust='split', series=None, infer=None, on_mismatch='skip', demerger='estimate') ¶

    Daily OHLCV for an NSE stock (or index) from the official bhavcopy archive.

    Parameters:

    Name Type Description Default
    symbol str

    NSE ticker ("RELIANCE"), an old ticker ("ZOMATO"), or an index name ("NIFTY 50", "BANKNIFTY", "INDIA VIX").

    		 required
    start DateLike

    Any date-like; default is the last 365 days.

    		 None
    end DateLike

    Any date-like; default is the last 365 days.

    		 None
    adjust str | None

    "split" (default) adjusts for splits, bonuses, consolidations and rights; "total" also for dividends (use for return calculations); None = raw only. Adjusted prices are expressed in the share terms of the last row returned.

    		 'split'
    demerger str

    "estimate" (default) adjusts demergers/schemes using the ex-date price discovery (flagged check="estimated"); "ignore" leaves them unadjusted.

    		 'estimate'
    series Sequence[str] | None

    Restrict to series, e.g. ["EQ"]. Default picks the best series per day (EQ, then BE, BZ, ...), so stocks moved to trade-to-trade stay continuous.

    		 None

    Returns:

    Type Description
    DataFrame indexed by IST date with raw ``open high low close last prev_close volume
    turnover trades`` and, when adjusted, ``adj_open adj_high adj_low adj_close
    adj_volume adj_factor``. ``df.attrs["events"]`` holds the factor table.

    factors(symbol, start=None, end=None, *, adjust='split', infer=None, on_mismatch='skip', demerger='estimate') ¶

    The adjustment-factor table behind :func:history (one row per event).

    Includes cumulative_factor: the multiplier applied to prices before that ex-date.

    index_history(name, start=None, end=None) ¶

    Daily OHLC (+ volume, turnover, P/E, P/B, dividend yield) for an NSE index.

    market(day=None, series=('EQ',)) ¶

    The whole NSE equity bhavcopy for one day (default: latest available).

    universe(start, end=None, series=('EQ', 'BE')) ¶

    Panel of every stock that traded in the range (includes later-delisted names).

    Useful to avoid survivorship bias. Returns a long frame indexed by (date, symbol).

    Corporate-action adjustment: the factors, where they came from, and whether prices agree.

    How it works
    1. Corporate actions come from NSE's own corporate-actions feed (cached), parsed by :func:bhavpy.sources.nse_corpactions.parse_subject.
    2. Each event becomes a price factor applied to every price before its ex-date:

    ============== ========================================= =========================== action factor example ============== ========================================= =========================== split new FV / old FV FV 10 -> 2 : 0.2 consolidation new FV / old FV FV 1 -> 10 : 10 bonus a:b b / (a + b) 1:1 : 0.5 rights a:b @S TERP / P, TERP = (bP + aS) / (a + b) only when S < P dividend D (P - D) / P (adjust="total" only) CRSP-style total return ============== ========================================= ===========================

    P is the last close before the ex-date (the cum price). 3. Price check. For splits, bonuses and consolidations the overnight move open(ex) / P must be within 25% of the factor. If the market says otherwise the record is reported with check="mismatch" and not applied (configurable). 4. Gap scan. Overnight jumps that look like a split/bonus but have no matching record are reported as unexplained_gap (and applied only with infer=True, or automatically when the corporate-action feed is unreachable).

    The output of :func:factors shows every event, its factor, its source and its check, so the adjustment is fully auditable.

    corporate_actions(symbol, *, refresh=False) ¶

    Raw NSE corporate-action records for symbol and all its former tickers.

    build_events(actions, prices, *, mode='split', infer=None, on_mismatch='skip', demerger='estimate') ¶

    Turn corporate-action records + raw prices into an auditable factor table.

    prices is a raw daily frame indexed by IST date with open and close. mode: "split" (splits, bonuses, rights) or "total" (also dividends). infer: apply split-like price gaps with no record (None = only if feed failed). on_mismatch: "skip" or "apply" records the price check contradicts. demerger: "estimate" (default; see :func:_demerger_factor) or "ignore".

    cumulative(index, events, column='price_factor') ¶

    Product of factors of applied events with ex_date strictly after each date.

    apply(prices, events) ¶

    Add adj_open/high/low/close/volume and adj_factor columns to a raw price frame.

    Index constituents: current (NSE Indices files) and point-in-time.

    Point-in-time membership avoids survivorship bias in backtests:

    • NIFTY 50 - reconstructed by walking NSE's published index changes (bundled in data/nifty50_changes.csv, each row citing the NSE press release) back from today's list. Covers 2016-04-01 onwards; the walk is verified to keep exactly 50 names.
    • Other indices - bhavpy stores a dated snapshot each time it downloads a list, so history builds up from your first use (or from a scheduled bhavpy update).

    available() ¶

    Indices with a downloadable constituent list.

    nifty50_changes() cached ¶

    Bundled NIFTY 50 change log: effective_date, removed, added, source.

    nifty50_members(as_of, current) ¶

    Walk the change log back from current to the membership on as_of.

    constituents(index='NIFTY 50', as_of=None) ¶

    Members of index today, or on as_of where history allows.

    Returns columns symbol, name, industry, isin (name/industry/isin may be empty for historical members that have since left the index).

    Symbol master: current listings, ISINs, symbol/name changes, delistings.

    Old tickers keep working: bhavpy.history("ZOMATO") resolves to ETERNAL and stitches both symbols' history together, using NSE's own symbol-change file.

    Segment dataclass ¶

    symbol was the ticker from start (inclusive) to end (exclusive); None = open.

    equity_list(include_sme=True) ¶

    Currently listed NSE equities: symbol, name, series, listing_date, isin, face_value, board.

    symbol_changes() ¶

    Every NSE symbol change: old_symbol, new_symbol, effective_date, name.

    chain_from(symbol, changes, listed) ¶

    Pure function behind :func:symbol_chain (testable without network).

    symbol_chain(symbol) ¶

    All tickers this security traded under, oldest first, with validity windows.

    resolve(symbol) ¶

    Today's ticker for symbol (follows NSE symbol changes).

    info(symbol) ¶

    Listing details plus history for a symbol (current or old).

    Futures & options: daily bhavcopy, futures history, live option chain, lots, expiries.

    bhavcopy(day=None) ¶

    Full F&O bhavcopy for one day (default: latest available): futures and options.

    The raw file is cached once (~1 MB/day); futures rows also go into the futures table.

    futures(symbol, start=None, end=None, *, expiry='near') ¶

    Daily futures OHLC/OI for symbol.

    expiry: "near" / "next" / "far" for a continuous series built from the 1st/2nd/3rd contract on each day, or "all" for every contract.

    options(symbol, day=None, expiry=None) ¶

    End-of-day option rows for symbol on one day (from the bhavcopy).

    expiries(symbol='NIFTY') ¶

    Upcoming expiries (live, from NSE's option-chain contract info).

    expiry_calendar(symbol='NIFTY', start=None, end=None) ¶

    Historical + scheduled expiry dates for symbol's derivatives.

    Built from F&O bhavcopies sampled once a week (every listed expiry appears in each day's file), so a decade costs ~500 downloads once, then it is cached.

    option_chain(symbol='NIFTY', expiry=None) ¶

    Live option-chain snapshot (long format: one row per strike x CE/PE).

    This is the one dataset that only exists on NSE's live site; it is fetched with a normal browser-like request and never cached for more than a minute. df.attrs holds timestamp and underlying_price.

    lot_sizes() ¶

    Current F&O lot sizes per symbol and contract month (long format).

    NSE trading calendar: holidays, special sessions (Muhurat, Budget-day, DR drills), expiries.

    Sources, in order of trust:

    1. NSE holiday-master API (2011 onwards, incl. future scheduled holidays), cached.
    2. A bundled calendar (data/nse_calendar.csv) built from the API plus the bhavcopy archive itself: a weekday with no bhavcopy is a closure, a weekend/holiday with one is a special session. This covers 2005 onwards and works offline.
    3. Days the cache has seen (a settled 404 for a weekday = closure).

    holidays(year=None, *, include_weekends=False) ¶

    Equity-segment holidays for year (default: this year).

    Columns: description, weekday, muhurat_session (True when a special evening session was/will be held), source. Index: IST date.

    special_sessions() ¶

    Known sessions held on weekends or holidays (Muhurat, Budget day, DR drills).

    trading_days(start, end=None) ¶

    Regular trading days (weekdays that are not holidays) plus known special sessions.

    candidate_days(start, end) ¶

    Days worth asking the archive for: trading days plus Muhurat-holiday evenings.

    Institutional flows and large trades: FII/DII cash activity, bulk and block deals.

    fii_dii() ¶

    Latest FII/FPI and DII provisional cash-market activity (Rs crore).

    Each call also stores the day in the cache; :func:fii_dii_history returns everything stored so far (NSE publishes only the latest day).

    fii_dii_history(start=None, end=None) ¶

    All FII/DII days stored in the cache (wide: fii_buy, fii_sell, fii_net, dii_...).

    bulk_deals(start=None, end=None) ¶

    NSE bulk deals (>0.5% of shares in one client's trades in a day). Default: last 30 days.

    block_deals(start=None, end=None) ¶

    NSE block deals (single trades >= Rs 10 crore in the block window). Default: last 30 days.

    BSE daily equity data and NSE <-> BSE mapping by ISIN.

    bhavcopy(day=None) ¶

    Whole BSE equity bhavcopy for one day (default: latest available).

    history(code, start=None, end=None) ¶

    Daily OHLCV for a BSE security by scrip code ("500325"), ISIN, or BSE ticker.

    BSE tickers exist in the files only from 2024-07-08; scrip code and ISIN work for the whole archive. Prices are unadjusted (corporate actions: use the NSE series).

    nse_bse_map(day=None) ¶

    Securities listed on both exchanges, joined by ISIN.

    Columns: isin, nse_symbol, nse_series, bse_code, bse_symbol, bse_group, name.

    bhavpy update: bring the cache up to date incrementally.

    update(start=None, *, indices_only=False) ¶

    Fetch every missing day since the last cached day (or since start).

    Updates: NSE equity bhavcopies, NSE index closes, FII/DII flows, symbol lists and constituent snapshots. Returns a summary dict. Safe to run repeatedly (e.g. daily from cron or a scheduled GitHub Action): settled days are never re-downloaded.

    Runtime settings: cache location, politeness limits, timeouts.

    Change them with :func:bhavpy.configure or environment variables (BHAVPY_CACHE_DIR, BHAVPY_RATE, BHAVPY_OFFLINE).

    configure(**kwargs) ¶

    Change settings, e.g. bhavpy.configure(cache_dir="~/data/bhavpy", rate=2).

    Returns the active :class:Settings.

    Exception hierarchy.

    Every error raised by bhavpy derives from :class:BhavpyError, so callers can catch one type. The subclasses say why something failed, because the fix is different in each case: wait and retry, update the library, or check the input.

    BhavpyError ¶

    Bases: Exception

    Base class for all bhavpy errors.

    NotAvailable ¶

    Bases: BhavpyError

    The exchange has no file for this request (holiday, not yet published, or before the archive starts). Not a bug: the data simply does not exist at the source.

    BlockedError ¶

    Bases: BhavpyError

    The exchange refused the request (HTTP 401/403/429, or a bot-check page).

    bhavpy never tries to get around such blocks. Wait a while, lower the request rate (bhavpy.configure(rate=...)), or use the archive-based functions, which are rarely blocked.

    FormatChanged ¶

    Bases: BhavpyError

    A file or JSON response no longer has the shape bhavpy expects.

    This usually means the exchange changed a URL or column layout. Please open an issue with the message text; the daily live test suite normally catches these within a day.

    SymbolNotFound ¶

    Bases: BhavpyError

    The symbol could not be resolved, even through rename/delisting history.

    NetworkError ¶

    Bases: BhavpyError

    The request failed after all retries (timeouts, DNS, connection resets).
